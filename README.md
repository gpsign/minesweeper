# Minesweeper 🏴💣

A version of the classic game **Mine Field** created with **React**, **TypeScript**, and **Vite**.

<!-- ![Minesweeper Preview] -->

## 🎮 About the Game

**Minesweeper** is a game of logic where the goal is to uncover all the cells on a board without clicking on a mine. The cells contain numbers that indicate how many mines are nearby. It is up to the player make strategic decisions.

✅ User-friendly interface  
✅ Adjustable levels of difficulty  
✅ Smooth animations  
✅ Created using contemporary technologies  

Play now: [Minesweeper Online](https://minesweeper-nine-jade.vercel.app) 🎉

---

## 🚀 Technologies

- [React](https://react.dev/) – Interactive interface library  
- [TypeScript](https://www.typescriptlang.org/) – Static type checking for JavaScript  
- [Vite](https://vitejs.dev/) – Ultra-fast build tool

## 📦 Installation and Running

If you want to run the project locally, follow the steps below:

### 1️⃣ Clone the repository:
```bash
git clone https://github.com/gpsign/minesweeper.git
cd minesweeper
```

### 2️⃣ Install the dependencies:
```bash
npm install
```

### 3️⃣ Start the development server:
```bash
npm run dev
```

Now, access `http://localhost:5173/` in your browser! 🚀
